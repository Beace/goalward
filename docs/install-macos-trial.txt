Goalward — macOS 试用版安装说明

适用设备
  Apple Silicon（M 系列芯片）Mac，macOS 13.3 或更新版本。
  本包仅包含 arm64，不支持 Intel Mac。
  应用本身无需 Node.js、Rust、Xcode 或开发服务器。

安装
  1. 双击打开 DMG。
  2. 将 Goalward.app 拖到 Applications（应用程序）文件夹。
  3. 从“应用程序”打开 Goalward，然后推出安装磁盘。
  使用 ZIP 备用包时，解压后把 Goalward.app 移到“应用程序”即可。

首次打开的 macOS 提示
  这是本地 ad-hoc 签名、尚未经过 Apple 公证的试用包。
  如果提示无法验证开发者 / Apple 无法检查 App，请先确认文件由你信任的
  发送者提供。尝试打开后，到“系统设置 → 隐私与安全性”，找到 Goalward
  的提示并选择“仍要打开”，再按系统提示确认。
  企业管理的 Mac 可能不允许该操作，请联系设备管理员。
  如果系统提示恶意软件或文件已损坏，请停止安装并联系发送者，重新核对文件。
  Apple 官方说明：https://support.apple.com/zh-cn/102445

连接 Agent Runtime
  首次启动会检测当前用户安装的 Codex、Claude Code、Kimi CLI、Pi、
  DeepSeek Harness 和已有模型配置。选择检测结果导入，或进入“手动配置”。
  未检测到时，先按相应 Runtime 的官方说明安装并完成登录，再点击“重新检测”。
  若程序安装在自定义路径，在设置中选择完整可执行文件路径并进行检测。
  本应用管理外部 CLI，不附带这些 Runtime、模型权重、订阅或 API 凭据。
  外部 Runtime 可能有它自己的系统 / Node.js 版本要求。
  从 Finder 启动不会读取 shell profile 里的自定义别名或仅在终端中 export 的
  环境变量。优先使用 Runtime 自身支持的持久化登录和配置方式。

开始使用
  先把大方向写成目标，说明期待的结果与判断进展的依据，再拆出第一项任务。
  任务要读写本地文件时，选择实际存在的目录，再选择 Runtime、模型和思考强度。
  访问权限在“设置 → 运行时”中配置；按需要选择读取、写入与工具权限。
  可使用普通目录，不要求 Git 仓库。示例任务只用于展示，不会执行真实命令。
  发送指令后可查看对话、运行状态、执行过程及产物；复盘结果再决定下一步。
  Codex / Claude Code / Kimi CLI / Pi 有专用协议适配；其他通用 CLI 需配置
  可执行路径、参数与输入方式。

数据与升级
  聊天、任务、Runtime 配置和执行记录保存在本机当前用户目录：
  ~/Library/Application Support/dev.goalward.desktop/
  首次启动 Goalward 前先退出旧版应用。Goalward 会保留旧版数据目录，
  并尝试非覆盖迁移已有数据；旧附件仍可能引用旧目录，请勿提前删除。
  安装包不包含发送者的聊天、账号、凭据或本地 Runtime 配置。
  升级前结束任务并退出应用，再用新版替换“应用程序”内的旧版。
  本试用版没有自动更新。卸载应用不会自动删除上述用户数据目录。

文件完整性
  发送者同时提供 SHA256SUMS.txt，可在安装包所在目录运行：
  shasum -a 256 -c SHA256SUMS.txt
  校验文件需要与安装包来自同一个可信发送者。
